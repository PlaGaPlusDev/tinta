# tinta

**Qué es:** editor de vaults Markdown estilo Obsidian, pero con UI 100% nativa
Rust (egui). Sin Chromium, sin Node, sin webview. Consumo esperado: 40–90 MB RAM.

**Origen:** reconstrucción informada por análisis REA (reuse Reverse Engineer
Anything) de Obsidian 1.13.7 desktop (Electron):
- Shell main: `app.asar` (actualizador + protocolo + IPC)
- Renderer: `obsidian.asar` (CodeMirror, PixiJS, i18next, ~20 core plugins)

**MVP (0.1.0):**
- [x] Abrir carpeta como vault + escaneo *.md (walkdir)
- [x] File explorer lateral
- [x] Editar con autosave manual (Ctrl+S) + indicador de sucio
- [x] Vista lectura renderiza Markdown (pulldown-cmark + syntect en bloques de código)
- [x] Wikilinks `[[…]]` resueltos por título o ruta
- [x] Backlinks por nota (panel inferior)
- [x] Quick switcher fuzzy (Ctrl+O)
- [x] Paleta de comandos (Ctrl+P)

**Iteración 0.2.0** (basada en core plugins de Obsidian, build CI verde):
- [x] Búsqueda textual en vault (Ctrl+Shift+F) — core "search"
- [x] Outline/esquema de headings (panel derecho) — core "outline"
- [x] Tags `#tag` indexados + chips clicables → abren búsqueda
- [x] Nota diaria `YYYY-MM-DD.md` — core "daily-notes"
- [x] Wikilinks clicables en modo lectura (navegación)
- [x] Conteo de palabras — core "word-count"
- [x] Resolución de wikilinks por ruta (`[[carpeta/nota]]`)

**Roadmap (0.3.0+):**
- [x] Grafo de notas (equivalente PixiJS de Obsidian, en egui painter) — 0.3.0
- [x] Watcher de cambios en disco (crates `notify`, debounce 400 ms, recarga si no hay edición local) — 0.4.0
- [ ] Ctrl+click wikilinks en modo edición (requiere caret API de egui)
- [ ] Scroll-to-heading desde outline
- [ ] Tags panel global (todas las tags del vault)
- [ ] Empaquetar AppImage/DEB desde CI
- [ ] Migrar `egui::Id::new` deprecado → `IdSalt`
