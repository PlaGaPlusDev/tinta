# DevLog — tinta

## Sesión de hoy

- **REA (Reverse Engineer Anything)** instalado y conectado a OpenCode vía `npx rea-agents setup` (registro MCP en `~/.config/opencode/opencode.jsonc`, requiere reinicio del agente para exponer los 207 tools).
- **Análisis REA de Obsidian 1.13.7**: `app.asar` completo parseado (evidence `/tmp/opencode/rea-main.json`). El `obsidian.asar` (app.js 25 MB) OOM-muere localmente → sustituido por greps estáticos dirigidos.
  - Recon: updater RSA, protocolo `app://`, renderer con CodeMirror + PixiJS + i18next, ~20 core plugins.
  - Eventos del watcher externos encontrados: `onCreate`×99, `onDelete`×77, `onRename`×21, `onModify`×8.
- **Decisiones de arquitectura**: egui 0.37 (backend glow, sin webview), compilación 100% en GitHub Actions por límite de RAM local (~1.8 GB, build local OOM), binario objetivo ~13 MB con RSS ~85 MB.
- **0.1.0 (MVP)**: explorador, editor, lectura markdown + syntect, wikilinks, backlinks, switcher fuzzy, paleta. Release en GitHub con binario adjunto.
- **0.2.0** (basado en core plugins): búsqueda en vault (Ctrl+Shift+F), outline, tags indexados + chips, nota diaria, wikilinks clicables en lectura, conteo de palabras. Ciclo de errores 23→10→6→3→1→0 en CI.
- **0.3.0**: grafo de notas con `egui::Painter` (nodos clicables, hover, aristas = links, layout circular, nota actual en rojo). Reemplaza el PixiJS de Obsidian.
- **0.4.0**: watcher con crate `notify` 8.2 (inotify), thread background, canal filtrado a `.md`, debounce de 400 ms, reindex + recarga si no hay edición local. Probado en vivo: escribiendo un `.md` externo tinta se queda estable (85 MB, log limpio).
- **Fuente de features**: cada iteración sale de un core plugin de Obsidian analizado con REA.
